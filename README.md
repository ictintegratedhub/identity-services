# ICT Integrated Hub - Identity Services

NIN and BVN verification service for staff use.

## Features
- Staff authentication with password
- NIN verification and slip printing
- BVN verification and slip printing
- Secure API endpoints

## Deployment
Deployed on Vercel.

## Environment Variables
- `JWT_SECRET`: Secret key for JWT tokens
- `STAFF_PASSWORD_HASH`: Hashed staff password
- `API_KEY`: 
- `API_BASE_URL`:

- Node.js (Vercel Serverless Functions)
- HTML/CSS/JavaScript
- JWT Authentication
